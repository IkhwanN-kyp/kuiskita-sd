# KuisKita 📚

Aplikasi latihan SD yang ramah layar sentuh. React + Vite, siap deploy ke Vercel.

## Jalankan

```bash
npm install
npm run dev
```

## Deploy

Import repository ini di Vercel, pilih framework Vite, lalu Deploy.

## Tambah materi

Ubah `src/data/materiData.js`. Foto buku dapat diletakkan di `public/images/buku-paket/`.

Fitur: ringkasan, kuis dengan pembahasan, mencocokkan dengan tap/drag, dan rekap bintang.
